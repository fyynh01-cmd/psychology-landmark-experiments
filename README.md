# 心理学里程碑实验速查 / Psychology Landmark Experiments

把《巴甫洛夫的狗：改变心理学的50个实验》蒸馏为一套可复用的**心理学实验速查 / 方法库**技能包。

- **覆盖**：心理学 50 项里程碑实验（`assets/experiments.md`），从达尔文蚯蚓实验到伦根哈格出体体验。
- **统一骨架**：每条均为「背景假设 → 方法设计 → 关键结果 → 意义影响」四段，支持按年份 / 分支 / 研究者 / 主题检索与结构化蒸馏改写。
- **示例**：`examples/milgram.md` 提供完整条目样板。
- **元数据与校验**：`meta.json`、`VALIDATION.md`。

## 结构

```
psychology-landmark-experiments/
├─ SKILL.md                     # 技能定义（何时使用/核心概念/工作流/规则/边界）

```

## 使用

- 想快速了解某实验 → 在速查表中按名称/年份定位条目。
- 想按年份/分支/主题横向检索 → 使用速查表中的索引维度。
- 想把某实验改写为科普/讲义/脚本 → 以四段骨架为纲，用自己的语言重组。
